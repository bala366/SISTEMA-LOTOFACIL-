# AutoFácil V3

Projeto Android para executar o motor Python do interpretador da Lotofácil.

- Jogo 1: melhor resultado encontrado em 250.000 candidatos ponderados sorteados.
- Jogo 2: melhor resultado após avaliar as 3.268.760 combinações de 15 dezenas.
- Android Gradle Plugin: 8.9.0
- Gradle: 8.11.1
- Java: 17
- Chaquopy: 16.1.0
- Python: 3.11

O workflow valida a sintaxe do motor Python antes de compilar o APK.
